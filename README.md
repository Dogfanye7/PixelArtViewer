# PixelViewer

Um visualizador simples de imagens/pixel art desenvolvido em .NET.

## Requisitos

* Windows
* **.NET 10 Desktop Runtime** instalado

O aplicativo **não é standalone**, portanto é necessário ter o .NET instalado para executá-lo.

## Avisos

* O aplicativo está disponível apenas em **português**.
* Não possui sistema de tradução/localização.
* **Não há previsão de novas atualizações.**
* O projeto pode conter **bugs, erros ou comportamentos inesperados**.
* Algumas funcionalidades podem não funcionar corretamente em todos os computadores ou configurações.
* Este projeto foi desenvolvido principalmente como um projeto pessoal/experimental.

Use por sua conta e risco.
